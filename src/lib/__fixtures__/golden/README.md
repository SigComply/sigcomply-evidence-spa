# CLI golden periods and catalogs

Copied byte for byte from `sigcomply-cli`. Never edit them by hand.

| File | CLI source | Generated by | Tested in |
|---|---|---|---|
| `periods.json` | `internal/planner/testdata/spa-golden/periods.json` | `TestSPAGoldenPeriods` | `src/lib/period-golden.test.ts` |
| `soc2_golden.json`, `iso27001_golden.json` | `internal/manualcatalog/testdata/` | `TestCatalogGolden` | `scripts/fetch-catalogs.test.ts` |

To refresh after a CLI change: in `sigcomply-cli`, run the generating test with `-update`
(`go test ./internal/planner/ -run TestSPAGoldenPeriods -update`,
`go test ./internal/manualcatalog/ -run TestCatalogGolden -update`), then here run
`npm run check:goldens -- --copy` and the gate. `npm run check:goldens` alone reports drift.
