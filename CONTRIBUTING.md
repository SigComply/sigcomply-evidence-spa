# Contributing to the SigComply Evidence SPA

Thanks for contributing! This is a static, backend-free React + TypeScript
single-page app. The broader engineering rules, architecture, cross-repo
contracts, and conventions live in [`CLAUDE.md`](./CLAUDE.md); the change loop
and testing details live in [`docs/WORKFLOW.md`](./docs/WORKFLOW.md) and
[`docs/TESTING.md`](./docs/TESTING.md).

## Security issues

Do **not** open a public issue for a vulnerability. Report it privately — see
[`SECURITY.md`](./SECURITY.md).

## Getting started

```bash
npm install
npm run dev        # http://localhost:5173, uses committed catalog JSONs
```

## Local verification gate

CI does not lint, test, or typecheck — **local is the gate**. Before every
commit, all four must be clean:

```bash
npm run lint       # eslint . — the only style gate
npm run test       # vitest run
npx tsc -b         # strict typecheck
npm run build      # tsc -b + vite build
```

UI changes should also be verified in the browser (`npm run dev` or
`npm run preview`).

## Conventions (summary — full list in `CLAUDE.md`)

- **TDD + small atomic commits**, all checks green per commit. Commit format
  `<type>: <description>` (`feat`/`fix`/`refactor`/`test`/`docs`/`chore`) with a
  `Co-Authored-By:` trailer where applicable.
- **Docs are part of "done"** — update the focused doc your change touches
  (`CLAUDE.md`, `docs/WORKFLOW.md`, or `docs/TESTING.md`) in the same commit.
- **Scope guardrails** — the form generator only handles user attestations
  (`declaration` + `checklist`). Don't add form types for evidence that already
  exists as a file; that's uploaded to the bucket directly.
- **Keep verify crypto in Web Crypto** — don't pull in a JS Ed25519 library.
- **`src/lib/verification/canonical.ts` mirrors the CLI's canonicalization
  byte-for-byte.** Any drift silently breaks signature verification — keep the
  two in lockstep.
- **Don't hand-edit `src/components/ui/`** — those are generated by
  `npx shadcn add <name>`.
- Use the `@/…` path alias, not relative `../../` imports.

## Cross-repo contracts

The catalog JSON and `EvidenceEnvelope` shapes are shared with
[`sigcomply-cli`](https://github.com/SigComply/sigcomply-cli). See
[`CLAUDE.md` → Contracts with Sibling Repos](./CLAUDE.md#contracts-with-sibling-repos)
before changing either — a change on one side must land on both.
